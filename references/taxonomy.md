# 分类、风格与情境引用

## 分维度标注

| 维度 | 例子 | 判断注意 |
|---|---|---|
| 体裁 | 五绝、七绝、五律、七律、古体诗、乐府、词 | 字数不等于合律，篇幅相同也未必是近体诗；乐府兼具来源与文体信息 |
| 题材 | 边塞、战争、送别、羁旅、思乡、山水田园、咏物、怀古、咏史、闺怨、悼亡 | 可多选；写到边塞不一定赞美战争，写战争也未必发生在边塞 |
| 风格 | 婉约、豪放、清新、雄浑、沉郁、含蓄、明快、苍凉、绮丽 | 用具体措辞、节奏、意象、视野和语气支撑；不沿用作者标签代替单篇判断 |
| 情感 | 喜悦、惜别、思念、孤独、悲愤、惆怅、眷恋、旷达 | 可有转变、交织和反讽，不强制一首一种情绪 |
| 技法 | 借景抒情、以乐景写哀、白描、对照、用典、虚实相生、反问、留白 | 指到具体句子，解释效果，不能只背术语 |
| 词牌／词体 | 如梦令、浣溪沙；所选具体词体 | 词牌是格式，标题或题序才可能说明主题；同词牌有变体 |

“出塞”可能是作品题目、乐府题或题材提示，按当前作品分别标；不要仅凭题目就认定七绝或某种固定情感。“婉约词”同时涉及词的体裁和婉约风格；“边塞诗”是题材分类。唐诗与宋词是时代、文学类别，也不能代替精确体裁。

精读时挑真正有解释力的主标签，附一两句依据；拿不准时用描述性词语或注明暂定，避免密集贴标签。分类索引允许一首进入多个题材，计数时注明多重标注，不能把标签数量称为作品数。

## 风格比较

从相似题材或表达任务入手：例如都写送别，但一个劝饮，一个远望，一个用景收束。对照关键诗句、动作、视野、语气及留白，再指出风格差别；不是“王维都是清新、苏轼都是豪放”。合适时用 Mermaid 展现同题材的不同表达路径。

风格术语是阅读工具，不是质量评级；不把豪放写成更高级，也不把婉约等同于软弱。时代、作者与具体作品关系要保留弹性。

## 情境引用索引

按用户常见感受建立入口，如「夜里想家」「朋友远行」「独处但自在」「失意后自勉」「春日喜悦」「怀念逝者」。每条包括：情境、原句、作者篇名、笔记链接、原语境、当前契合点与可能误用。

- 优先推荐已背、已读作品，用户要求可扩展；不能把尚未确认的篇目说成“你背过”。
- 不因意象相同就认定适合：悼亡词与普通恋爱想念、家国悲愤与轻微烦恼，语境强度可能差异很大。
- 可以说明“借用这句表达某种相近感受”，不能说原作者本来就在表达用户的当代情境。
- 化用保留原句入口并标注改写。自创诗句、网络句子和古人名句区分，不编造作者或出处。
